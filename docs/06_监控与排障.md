# 监控与排障

## 监控接口

管理员令牌访问：

```bash
curl http://127.0.0.1:8080/metrics \
  -H "X-API-Key: $API_AUTH_TOKEN"
```

接口返回 Prometheus 文本格式，当前包括：

- `vg_http_requests_total`：按请求方法、固定路径和 HTTP 状态码统计请求量；
- `vg_http_request_duration_seconds`：按固定路径统计响应时间总和与次数；
- `vg_question_outcomes_total`：统计成功、澄清、不支持、未认证、越权和异常。

`/metrics` 本身不计入 HTTP 指标，避免抓取监控时产生监控噪声。问题原文、API Token 和店铺名称不会写入指标。

## 本地检查

```bash
docker compose ps
curl http://127.0.0.1:8080/health
docker compose logs --tail=100 ai-analytics nginx
```

若页面返回 502/504，先看应用容器是否为 `healthy`。应用容器退出时执行：

```bash
docker compose up -d
```

若修改了代码或配置，执行：

```bash
docker compose up -d --build --force-recreate
```

## 生产迁移

迁移到 ECS 时，Prometheus 或云监控系统定期抓取 `/metrics`；公网不直接暴露该接口，建议由 Nginx、内网或监控网络访问，并继续保留管理员令牌。日志通过 Docker 日志轮转和 `/app/logs` 宿主机挂载保存。
