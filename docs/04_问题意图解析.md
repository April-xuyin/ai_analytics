# 问题意图解析

自然语言不能直接安全地当作 SQL。系统先把问题转换为结构化意图：指标、维度、时间范围、排序、数量和筛选条件。

例如“最近30天销售额最高的前5个品牌”转换为：

```yaml
metric: sales_amount
dimensions: [brand]
time_range: last_30_days
sort: descending
limit: 5
```

`QuestionIntent` 定义统一输出结构；`IntentParser` 定义所有解析器必须遵循的接口；`RuleBasedIntentParser` 是当前透明、可测试的基线版本。以后外部大模型解析器实现相同接口，上层流程不需要改变。

基线解析器不是最终 AI 能力，它用于验证结构设计，并作为后续评测大模型是否真正带来提升的对照组。

## 百炼千问适配器

`BailianIntentParser` 使用百炼的 OpenAI 兼容接口，但仍返回统一的 `QuestionIntent`。API Key、接口地址和模型名来自环境变量，因此后续增加 DeepSeek 或 OpenAI 时不需要改变上层结构。

将 `.env.example` 复制为 `.env` 并按阿里云百炼控制台当前信息填写。真实密钥不得提交到 Git。自动化测试使用假客户端，不会调用真实 API 或产生费用。
