# 问数服务与回答结构

当前问数入口是 `QuestionService.ask(question)`：

```text
自然语言问题
  → MetadataCatalog 检索指标、表和术语
  → 固定意图路由
  → 固定问题函数生成 SQL
  → LocalQueryRunner 执行
  → AnalyticsAnswer 统一返回
```

`AnalyticsAnswer` 是统一回答结构，包含状态、提示信息、数据集、指标、口径、日期范围、SQL、结果行和检索上下文。以后接入 FastAPI 或 Web 页面时，可以直接将它转成字典或 JSON。

当前固定路由只用于验证端到端流程，不代表生产系统只支持固定句子。下一阶段将使用大模型输出结构化意图，随后逐步支持动态 Text-to-SQL。未知问题当前返回 `unsupported`，不会猜测或执行不受控 SQL。

## 命令行演示

`scripts/ask_question.py` 是当前阶段的完整链路入口：

```bash
uv run python scripts/ask_question.py "最近30天销售额最高的10个SKU是什么？"
```

它会读取 `.env`，调用 DeepSeek 解析问题，再将结构化意图交给安全查询服务。这个脚本用于本地验证；生产环境会将同样的服务逻辑接入 FastAPI 和 Web 页面。

## FastAPI 接口

当前后端接口：

```bash
uv run python scripts/run_api.py
```

检查服务：

```bash
curl http://127.0.0.1:8000/health
```

问数接口：

```bash
curl -X POST http://127.0.0.1:8000/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"最近30天销售额最高的10个SKU是什么？"}'
```

FastAPI 自动提供接口文档：`http://127.0.0.1:8000/docs`。

## 运营问数页面

启动服务后直接打开 `http://127.0.0.1:8000/`，即可使用运营端页面：

- 在输入框填写自然语言问题，点击“查询数据”；
- 页面默认展示查询状态、指标口径和结果表；
- 查询 SQL 放在“查看查询依据”折叠区域，方便分析师或开发排查；
- 页面当前是单轮问数 MVP，尚未包含登录、权限、历史记录和图表。

页面文件位于 `web/`，由 FastAPI 静态托管，不需要单独安装前端构建工具。

## API 访问保护

本地开发默认不启用登录。部署时在 `.env` 配置：

```env
API_AUTH_TOKEN=请生成一个随机长令牌
```

之后调用 `/ask` 必须携带：

```text
X-API-Key: 你的令牌
```

`/health` 保持公开，便于部署平台进行健康检查。当前这是单令牌保护，后续再扩展到用户、角色和数据范围权限。
