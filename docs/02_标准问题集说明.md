# 标准问题集说明

标准问题集位于 `evals/questions.yaml`，来源于 AWS Quick BI 看板、ADS/DWS 主题表和历史业务排查 SQL。

它不是限制业务人员只能问固定句子，而是用于：

- 覆盖典型业务场景；
- 保存相同意图的不同问法；
- 为 Text-to-SQL 提供标准示例；
- 建立可重复的自动化评测；
- 记录当前数据无法支持的需求。

## 状态含义

| 状态 | 含义 |
|---|---|
| `implemented` | 已有固定问数代码和测试 |
| `ready` | 当前本地数据可回答，待补标准 SQL |
| `clarification_required` | 问题缺少月份、SKU或阈值，系统应追问 |
| `unsupported` | 当前数据缺少必要字段，应说明无法回答 |
| `deferred` | 理论可计算，但暂缓到后续表或阶段 |

问题中的 `paraphrases` 用来模拟业务方不同表达；`expected_datasets`、`expected_metrics` 和 `expected_dimensions` 用来检查系统是否选对数据资产，而不是要求生成的 SQL 字符串完全一致。

## DeepSeek 小批量评测

下面命令默认真实调用 DeepSeek 10 次，只评测问题理解，不执行 SQL：

```bash
uv run python scripts/evaluate_deepseek.py --limit 10
```

输出总体准确率，以及指标、维度和时间范围的分项准确率。该命令会消耗少量 API 余额；普通 `uv run pytest` 使用假解析器，不产生模型费用。

评测中的失败样例要保留并分析。派生问题（例如“未完成目标天数”）不应让模型创造不存在的指标，而应映射到基础指标后由查询层计算；SKU 主键问题通常需要同时包含 `seller_sku` 和 `asin`。

## 当前覆盖场景

- 品牌经营总览与环比；
- 北极星及高价值订单目标；
- SKU 销售排行和店铺下钻；
- 新品 30/60/90/120 天周期表现；
- SKU 成功率、ACOS 和退款率；
- 月度销售复盘；
- 商品主数据和数据质量；
- 地区、价格带、利润拆解等未来扩展需求。
