## 2. DeepSeek 耗时与用量

32 道问题的一次评测：

- 模型调用：32 次；
- 输入 Token：35,148；
- 输出 Token：2,524；
- 累计模型耗时：30,707.15 毫秒；
- 平均模型耗时：959.60 毫秒/次。

成本按评测当时 DeepSeek 的输入/输出 Token 价格计算。报告保留 Token 用量，不写死可能变化的单价。

## 3. SQL 安全边界

`app/query/sql_security.py` 使用 `sqlglot` 解析语法树，DuckDB 和 MaxCompute 执行器共用同一策略：

- 只接受单条 `SELECT` / `WITH` 查询；
- 数据集和物理字段必须位于元数据白名单；
- CTE 名称和派生别名在语法树内受控放行；
- 拦截多语句注入、系统库、跨库表、`read_parquet`、`read_file` 等外部读取；
- 查询超时或执行失败时记录 `query_error` 审计状态，API 不暴露底层异常。
